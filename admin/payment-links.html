How Payment Links Work

A payment link lets you request a specific amount without building a separate checkout page for every order.

01
Create Set amount, customer and order details.
02
Share Send the branded link to your customer.
03
Pay Customer completes OnePay checkout.
04
Verify Backend verifies and updates the order.

OnePay Tips

Best practices for production payment links.

✓
Always use an order ID This keeps the payment connected to the original website order.
🔒
Verify on the server Never trust a frontend success screen as proof of payment.
↗
Keep links short A short branded payment URL is easier to share and remember.
