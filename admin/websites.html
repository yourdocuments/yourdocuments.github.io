SNK OnePay Integration Flow

The production architecture will keep payment credentials and verification logic on the server side.

01
Create Payment Website sends order and amount to SNK OnePay API.
02
Checkout Customer completes payment inside branded OnePay checkout.
03
Provider bKash, Nagad or card provider processes the payment.
04
Webhook Provider sends payment event to secure backend.
05
Verify & PAID Backend verifies payment and marks the original order paid.
